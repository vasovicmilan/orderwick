# Licences and protecting the game (not legal advice – have a lawyer review it before release)

## What goes into the game and under which licence
| Part | Licence | What you must do |
|---|---|---|
| Your code, pixel art (cards, board, HUD, icon, trophies) | your copyright | nothing; see `LICENSE.txt` |
| Music and effects | generated by your code (`tools/make_audio.py`), no third-party samples | nothing; see the AI note below |
| Public Pixel font (GGBotNet) | CC0 | nothing (crediting is a nice gesture) |
| Pixel Operator 8 font (Jayvee Enaguas) | CC0 (licence text ships next to the font) | keep `PixelOperator8-LICENSE.txt` |
| pygame-ce | LGPL-2.1+ (the project itself says closed-source and commercial games are fine) | ship the LGPL text + notice; the libraries stay separate files (that is why `onedir`, not `onefile`) |
| SDL2, SDL_image/mixer/ttf, FreeType, HarfBuzz, libpng, libjpeg, libwebp, libtiff, ogg/vorbis/opus/FLAC/WavPack | zlib / BSD / MIT / FTL | their texts ship with the game (`licenses/third_party/`) |
| libmpg123, libsndfile, FluidSynth, libxmp, ALSA | LGPL-2.1+ | same as pygame-ce: separate libraries + licence text; do not modify them |
| Python, PyInstaller | PSF / GPL with an exception for built programs | nothing for your code |

All texts are in `licenses/`, and `THIRD_PARTY_NOTICES.txt`, `LICENSE.txt` and `EULA.txt` go into every build (`packaging/Orderwick.spec`,
`packaging/build.py`). The library texts were copied from the pygame-ce source (`docs/licenses`).

**Notes**
* The Pixel Operator family is listed on dafont as "Public Domain / GPL / OFL"; the file I used carries the CC0 text. For zero risk keep the licence file
  next to the font (OFL would also allow commercial use).
* If you ever add third-party images, sounds or fonts: record the author and licence here and in `THIRD_PARTY_NOTICES.txt`. Avoid CC-BY-NC, GPL and "free for personal use".
* **AI disclosure:** stores such as itch.io ask whether AI was used while making the game (art/code/sound); answer truthfully. This code was written with AI
  help, and the sound is produced by code written with AI help – answer honestly in the "Pre-Generated" part. The pixel art is yours. Because of copyright
  rules for AI content (in the US a purely AI-made work without human authorship is weakly protected), do not ship content you did not edit or choose yourself.
* The name "Orderwick" is generic: before release check that it is free on itch.io, in the EUIPO/USPTO databases and on the web.

## How to protect the game
1. **Copyright arises by creating the work** (Berne Convention); put the © notice (already in `LICENSE.txt`; you can add year and name to the About screen).
2. **EULA** (`EULA.txt`) – the agreement with the player (no copying/reselling/reverse engineering). The store's own terms apply too.
3. **Name/logo:** a trademark protects the name and logo, not the code; registering is optional and costs money.
4. **Rights to code/assets:** keep the repo private (GitHub private), keep the `.aseprite` sources – they are proof of authorship. Optionally register the work (US: copyright.gov) if you need it for a lawsuit.
5. **Technical protection is limited:** PyInstaller packs bytecode that can be decompiled, and PNG/OGG files stay in the folder. Options: Nuitka (compiles to C, harder to
   break), PyArmor (obfuscation, paid for commercial use), or packing the assets into one archive. None of that stops a determined pirate – real protection is the licence +
   DMCA reports + the account-bound activation key. Do not rely on DRM. Do not spend much time on this.
6. **Open-source licence?** If you sell the game, do not put the code under MIT/GPL. If you ever open the code, license the assets (art, sound) separately
   (e.g. CC-BY-NC-ND) and the code under MIT/GPL – but only after thinking about sales.

## Before release – checklist
- [ ] Set `AUTHOR_NAME`, `VERSION`, `LINKS` in `config.py`; in `packaging/Orderwick.spec` change `bundle_identifier` (`com.orderwick.game`).
- [ ] A lawyer reviews `EULA.txt`; a privacy policy is needed as soon as `SERVER_URL` is set (online features send data, see `docs/ONLINE.md`). The server ships a draft at `/privacy` and `/terms`: have a lawyer review both, . Confirm the minimum age (16+ in the draft) and the data-controller details.
- [ ] Check the game name (trademark/itch.io).
- [ ] All licence texts are in the build (the selftest does not check this – look into `dist/Orderwick/licenses`).
